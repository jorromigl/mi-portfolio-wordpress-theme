# Mi Portfolio Literario — WordPress Theme

A modern, user-friendly WordPress theme for literary portfolios. Manage your blog, books, and services without touching code.

## Features

- Custom Post Types: Dedicated "Mis libros" and "Servicios" sections
- Easy Content Management: ACF Pro fields for simple, visual editing
- Responsive Design: Mobile-first, works on all devices
- Elegant Typography: Curated fonts and color scheme
- Built-in Formspree Integration: Contact form included

## Requirements

- WordPress 6.0+
- PHP 8.0+
- ACF Pro (Advanced Custom Fields)

## Installation

1. Download the theme folder to `wp-content/themes/mi-portfolio-wordpress-theme/`
2. Activate the theme in WordPress Admin → Appearance → Themes
3. Install ACF Pro if not already installed
4. Go to Appearance → Customize to set up colors and fonts (optional)
5. Start adding content!

## Quick Start

### Add Your First Book

1. Go to **Mis libros** → **Add New**
2. Fill in: Title, Synopis, Cover image, Category, Publication date, External link (optional)
3. Click **Publish**

### Write a Blog Post

1. Go to **Entradas** → **Add New**
2. Write your post
3. Choose category (Lecturas, Escritura, Corrección)
4. Click **Publish**

### Edit Services

1. Go to **Servicios** → Edit existing or create new
2. Add description, icon, and button text
3. They'll appear on the homepage automatically
